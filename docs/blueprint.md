# **App Name**: Prismfolio

## Core Features:

- Hero Section with Typing Effect: Display a captivating headline with a dynamic typing effect to introduce the portfolio.
- Dynamic Project Gallery: Showcase projects in a dynamic grid with scaling hover effects and details (title, tech stack, live view button).
- Contact Form: Allow visitors to send messages, storing submissions in Firestore.
- Project Likes Counter: Implement a 'Likes' counter for each project using Firebase Realtime Database.
- Experience Timeline: Present a vertical, interactive timeline of professional experience.

## Style Guidelines:

- Background color: Deep charcoal (#121212) for a modern dark mode aesthetic.
- Primary color: Electric purple (#A78BFA) to add vibrancy and a futuristic touch.
- Accent color: Cyan (#64FFDA) as an accent for interactive elements and highlights.
- Font for headings: 'Poppins' (sans-serif) to maintain a contemporary feel.
- Font for body text: 'Inter' (sans-serif) to ensure readability.
- Implement a bento-grid layout for project cards.
- Apply smooth scroll animations and scaling hover effects to project cards.
